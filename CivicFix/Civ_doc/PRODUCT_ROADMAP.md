# Product Roadmap – CivicFix

## Phase 1: MVP
- Create issue reports.
- Select issue categories.
- Enter issue locations.
- View submitted reports.
- Update report statuses.

## Phase 2: Usability
- Search functionality.
- Category filters.
- Status filters.
- Dashboard statistics.
- Resolution rate.

## Phase 3: Future Enhancements
- User accounts.
- Image uploads.
- Interactive map.
- Email or mobile notifications.
- Backend database.
- Administrator dashboard.

## Product Direction
Start with a simple reporting workflow, evaluate user
needs and gradually introduce advanced functionality.
