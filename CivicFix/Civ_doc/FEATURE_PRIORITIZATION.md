# Feature Prioritization – CivicFix

Features are prioritized based on user value and implementation effort.

| Feature | Priority | Reason |
|---|---|---|
| Submit issue report | High | Core user need |
| View reports | High | Essential visibility |
| Update issue status | High | Supports tracking |
| Search reports | Medium | Improves discovery |
| Category filters | Medium | Improves organization |
| Dashboard metrics | High | Shows product performance |
| Map integration | Low for MVP | Requires mapping service |
| Notifications | Low for MVP | Requires backend |
| User authentication | Low for MVP | Requires account system |

## MVP Strategy
Build the reporting and tracking workflow first.

## Future Strategy
Introduce maps, notifications and user accounts after
validating the usefulness of the core workflow.
