# User Journey – CivicFix

## Stage 1: Discover
The resident opens CivicFix.

User Goal:
Understand how to report a community issue.

## Stage 2: Report
The resident enters:
- Issue title
- Issue category
- Location
- Reporter name
- Description

User Goal:
Submit a complete report.

## Stage 3: Track
The resident views the report in the dashboard.

User Goal:
Find the submitted report and understand its current status.

## Stage 4: Status Update
In this prototype, the status can be changed using the
Update Status button.

Possible Statuses:
- Reported
- In Progress
- Resolved

## Stage 5: Review
The dashboard displays total reports and resolution statistics.

User Goal:
Understand the overall status of recorded community issues.

## Improvement Opportunity
A future version could provide verified status updates,
notifications and a report history for each resident.
