# Success Metrics – CivicFix

## Primary Metric
Issue Resolution Rate.

Formula:

Resolved Reports / Total Reports × 100

## Supporting Metrics

| Metric | Definition |
|---|---|
| Total Reports | Total number of submitted reports |
| Reported Issues | Issues awaiting progress |
| In Progress | Issues currently being addressed |
| Resolved Issues | Issues marked resolved |
| Resolution Rate | Resolved reports divided by total reports |
| Category Distribution | Reports grouped by category |
| Pending Reports | Reports not yet resolved |

## Product Quality Metrics
- Report submission success rate
- Search usage
- Filter usage
- Repeat user activity

## Measurement Limitations
The current prototype uses browser Local Storage.
It does not collect real user analytics or independently
verify whether a community issue has been resolved.

These are proposed product metrics.
