# CivicFix – Community Issue Reporting & Resolution Platform

## Overview
CivicFix is a front-end prototype that allows residents to report
community issues and track their progress through different statuses.

## Problem Statement
Residents may have difficulty reporting local problems and knowing
whether reported issues have been addressed.

## Proposed Solution
CivicFix provides a simple interface for submitting reports,
viewing community issues and tracking their status.

## Target Users
- Local residents
- Community representatives
- Issue management administrators

## Features
- Submit community issue reports
- Select issue categories
- Add location and descriptions
- View all submitted reports
- Search reports
- Filter by category and status
- Update report status
- Delete reports
- View issue statistics
- Calculate resolution rate
- Save information using browser Local Storage

## Technology Stack
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run
1. Clone or download the repository.
2. Open the CivicFix folder.
3. Double-click index.html.
4. The application opens in your browser.

No database or additional software is required.

## Product Metrics
- Total reports
- Reported issues
- Issues in progress
- Resolved issues
- Resolution rate
- Category-wise report count

## Product Limitations
This is a front-end prototype.
Reports are stored locally in the browser.
There is no real municipal integration, authentication,
server-side database or verified resolution process.
